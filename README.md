# Проект `otus-playwright-hw`

Автотесты UI для сайта OTUS с использованием Playwright, Java, Guice и JUnit 5.

Реализованы четыре сценария, покрывающие ключевые пользовательские пути: работа с преподавателями, фильтрация каталога, переход на страницу для бизнеса и проверка подписки.

---

## 🚀 Требования

- **Java 17+**
- **Maven 3.8+**
- **Playwright** – установка через Maven (зависимость в pom.xml)
- **Браузеры** – Playwright автоматически загружает их при первом запуске

---

## 🧪 Запуск тестов

### Обычный запуск (все тесты)
```bash
mvn clean test
```
